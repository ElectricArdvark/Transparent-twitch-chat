# Features

Transparent Twitch Chat is a user script that improves your PogChamp experience in  **Fullscreen and Theater mode**.

* Chat width, location, and opacity are customizable
  * Click the current chat width value to set a custom value
* Chat filters (comma-separated list of words, see [the guide](https://github.com/chylex/Transparent-Twitch-Chat/wiki/Chat-Filters))
* Toggle between default purple theme and gray theme
* Individual or all badges can be hidden for less clutter
* Option to hide the thin chat edge border in transparent mode
* Option to keep chat transparent when hovering over chat
* Options to hide the chat header, input box, pinned cheer, and the conversation panel
* (Firefox only) Chat scrollbar is hidden by default and only appears when you scroll

### Tips

* The *Smooth Text Shadow* option makes chat look nicer, but is also very CPU intensive
* If you want fullscreen with chat, enter **Theater mode** and press **F11** (Firefox/Chrome/Opera) or **Shift+Win+Enter** (Edge)

# How to Install

1. Install a userscript manager browser extension:
    - [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
    - [Tampermonkey](https://www.tampermonkey.net/)
2. Click this link **[Github](https://raw.githubusercontent.com/ElectricArdvark/Transparent-twitch-chat/main/dist/TransparentTwitchChat.user.js)** - the extension will prompt you to install it. Enable auto-update (recommended).


### Changing the Settings

In order to change settings, click **Settings** from your userscript manager menu command, or move your cursor over the chat and click the gear icon in the bottom right corner. You can close the dialog by clicking the close button (✕), clicking the gear icon or menu command again, pressing the **Escape** key, or clicking anywhere outside the dialog area.
